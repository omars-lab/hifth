Each project goal gets its own file in `.claude/goals/<short-name>.md`, indexed in `.claude/goals/README.md`. The current one is `study-quran-pitch.md` (2026-11-09). Each file names the Claude tools (skills, hooks, make targets) used for each step, and the ones still to build, so progress is measured the same way every time.

**Why:** the owner asked (2026-11-09) "what is our current goal and how do we measure progress" after days of drift into Apple setup. Then they asked for one file per goal, and for each file to name the Claude tools, "so we can do things in a repeatable way".

**How to apply:** read the current goal before picking work. Update its numbers table after a pitch walk. When a goal ends, mark it done and start a new file rather than rewriting the old one. Related: [[poc-for-study-quran-team]], [[walk-app-growing-checklist]].
