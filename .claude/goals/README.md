# What goals is this project working toward?

One file per goal. Each says what the goal is, how progress is measured, the current numbers,
what comes next, and the Claude tools (skills, hooks, make commands) that make the work
repeatable. A session reads the **current** goal before picking work.

| Goal | Status | Started |
|---|---|---|
| [A demo good enough to show The Study Quran's team](study-quran-pitch.md) | **current** | 2026-11-09 |

## Adding a goal

Make a new file named for the goal (`<short-name>.md`), with the same sections as the current one:
the goal · are we on it · how we measure progress · the current numbers · what comes next · the
tools that make it repeatable · how to use the page. Add a row above. When a goal is met or
replaced, set its status to **done** (with the date) instead of deleting it.
