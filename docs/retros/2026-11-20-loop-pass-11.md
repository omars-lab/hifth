## Worth copying
- To size a code rewrite before doing it, write both shapes for a slice of the real code into
  scratch files, minify and gzip each with esbuild: one run gave 949 against 823 bytes.
- When no trim is in sight, the speed guide's rule (raise only with twice the room shown by a
  fresh timing run) turns a stuck trim into a measured 5 KB raise in one pass.
