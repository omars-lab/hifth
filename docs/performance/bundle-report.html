What does more code cost at start-up?

The app as built, then with extra code added that cannot be compressed, each opened by Lighthouse on the same pinned slow phone as the start-up check. Measured 2026-11-20.

The app starts in 2106 ms today, 394 ms inside the goal. The goal was met at every amount tried, up to +50 KB. On average each extra kilobyte cost 6.0 ms, but it arrives in steps of one network round trip, so a small addition can cost nothing or a whole step. This is for code that only has to download; code that also runs costs more, so leave room.
