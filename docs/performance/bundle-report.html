What does more code cost at start-up?

The app as built, then with extra code added that cannot be compressed, each opened by Lighthouse on the same pinned slow phone as the start-up check. Measured 2026-11-11.

The app starts in 2306 ms today, 194 ms inside the goal. The goal was still met with +50 KB and missed with +100 KB, so the room left is somewhere in between. On average each extra kilobyte cost 4.4 ms, but it arrives in steps of one network round trip, so a small addition can cost nothing or a whole step. This is for code that only has to download; code that also runs costs more, so leave room.
